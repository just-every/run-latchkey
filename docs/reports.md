# Security reports

Unlock your company vault, open Settings, then Security reports. The current vault owner can inspect permitted active items and retained successful connected human activity. Other readers and reviewers cannot open this initial reporting door. Personal and family vaults are excluded.

Choose 7, 30 or 90 days, or 12 months. Member reference and Item reference accept an opaque account or item UUID. Leave either empty to include all permitted activity. Usage action narrows the recorded action. These criteria filter usage only: posture and adoption keep the complete current vault scope, so selecting one member never makes the health denominator smaller.

Save report view retains the range and usage criteria. Selecting a saved view restores them; Generate report observes current sources again. A saved view is not a historical observation. CSV and PDF downloads include the exact selected criteria, as-of time, policy version and unknown coverage. Changing a criterion clears the old report. Changed vault authority or source revision requires a fresh report before export.

No matching usage means no matching retained facts, not proof that an item was never used. Missing machine, agent, offline and client-reachability sources remain unknown. Daily observations, monthly aggregates, historical policy comparisons and broader team and auditor authority remain incomplete under LKY-013.
